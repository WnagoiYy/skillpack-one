# Documents and Communication Router

1. Identify the target artifact, audience, source material, language, and layout constraints.
2. Read the locale-appropriate Atomic Skill index in `references/`.
3. Keep evidence research and data analysis as upstream atoms rather than hiding them inside a writing Skill.
4. Select one format atom or a capability pack when several artifacts are independently useful.

Do not route executable source code or image/video production here.
