# Productivity tools: Atomic Skills

Operate spreadsheets and knowledge tools while preserving structure and user control.

## Atomic Skills

- `atom-operate-knowledge-vault` — **Operate a knowledge vault**: Create or reorganize one bounded set of notes while preserving links, metadata, naming conventions, and user-owned knowledge.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-operate-spreadsheet` — **Operate a spreadsheet**: Apply one bounded spreadsheet edit while preserving formulas, formats, sheet structure, and a verifiable before-and-after state.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform

Read only the selected Atomic Skill. Use a capability pack when the request has independently useful outcomes.
