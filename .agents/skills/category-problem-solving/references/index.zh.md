# 问题研究: 原子 Skill

将模糊问题转化为问题框架、备选方案、决策、计划或评审。

## 子分类

- `category-decision-review` — **决策与评审**: 按标准比较方案，或依据明确量规评审产物。
- `category-ideation-planning` — **构思与计划**: 生成差异化方案并将选定方向转化为可执行计划。
- `category-problem-framing` — **问题定义**: 在求解前澄清目标、约束、相关方、假设与成功标准。
