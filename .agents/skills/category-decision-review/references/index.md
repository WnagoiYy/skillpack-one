# Decision and review: Atomic Skills

Compare options against criteria or critique an artifact against an explicit rubric.

## Atomic Skills

- `atom-compare-decisions` — **Compare decisions**: Compare a bounded option set against explicit weighted criteria, uncertainty, reversibility, and decision-sensitive trade-offs.
  - Risk: `read-only`
  - Lifecycle: analyze, verify
- `atom-critique-output` — **Critique an output**: Evaluate one artifact against an explicit rubric and return prioritized, evidence-located improvement findings without rewriting it.
  - Risk: `read-only`
  - Lifecycle: analyze, verify

Read only the selected Atomic Skill. Use a capability pack when the request has independently useful outcomes.
