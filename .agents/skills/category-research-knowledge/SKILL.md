# Research and Knowledge Router

1. Determine the evidence question, required source quality, and output claim.
2. Read the locale-appropriate file in `references/` for certified atoms.
3. Separate evidence collection from document production when both are requested.
4. Select the smallest atom set and retain source provenance through every handoff.

Do not route unsupported creative writing or implementation work here merely because it needs background reading.
