# Organize Personal Tasks

Extract commitments, clarify outcomes and deadlines, separate projects from next actions, identify dependencies, prioritize transparently, and return a reviewable task list. Do not create external tasks, calendar events, or reminders unless a separate authorized write atom is selected.
