# Design and media: Atomic Skills

Design interfaces or create and transform visual, audio, and video media.

## Atomic Skills

- `atom-create-technical-diagram` — **Create a technical diagram**: Create one accurate, editable technical diagram from verified components and relationships with a clear viewpoint, legend, scope, and accessible labels.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-design-interface-spec` — **Design an interface specification**: Define an implementation-ready UI and interaction specification
  - Risk: `reversible-write`
  - Lifecycle: plan, create
- `atom-design-presentation-visuals` — **Design presentation visuals**: Define and apply one coherent visual system for approved slide content, including hierarchy, layout, typography, color, imagery, charts, and accessibility.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-edit-image` — **Edit an image**: Apply one bounded transformation to a supplied image while preserving requested identity, content, dimensions, provenance, and unedited regions.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-generate-image` — **Generate an image**: Generate one original raster image from a bounded visual brief with composition, style, constraints, rights-aware references, and acceptance checks.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-plan-video-production` — **Plan video production**: Plan one video from audience and message through script beats, shots, assets, production constraints, accessibility, review, and delivery specifications.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform

Read only the selected Atomic Skill. Use a capability pack when the request has independently useful outcomes.
