# Implement a Code Change

Confirm the requested behavior and repository constraints, inspect the smallest relevant surface, edit only authorized files, and verify in proportion to risk. Preserve unrelated changes. Report the changed behavior, files, and test evidence. Do not use for plan-only or security-audit-only requests.
