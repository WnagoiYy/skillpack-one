# Personal productivity: Atomic Skills

Manage an individual's tasks, notes, calendar, memory, and attention.

## Atomic Skills

- `atom-capture-structured-notes` — **Capture structured notes**: Convert one bounded stream of supplied information into structured notes with source, context, decisions, actions, links, and unresolved questions.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform
- `atom-organize-personal-tasks` — **Organize personal tasks**: Convert unstructured commitments into a prioritized personal task list
  - Risk: `read-only`
  - Lifecycle: plan
- `atom-plan-learning-path` — **Plan a learning path**: Create one adaptive learning path from a learner's goal, baseline, constraints, resources, practice sequence, assessments, and review cadence.
  - Risk: `read-only`
  - Lifecycle: analyze, verify
- `atom-schedule-personal-calendar` — **Schedule a personal calendar**: Turn one person's approved commitments into a conflict-aware calendar plan and create events only with explicit authority and confirmation of material details.
  - Risk: `reversible-write`
  - Lifecycle: analyze, transform

Read only the selected Atomic Skill. Use a capability pack when the request has independently useful outcomes.
