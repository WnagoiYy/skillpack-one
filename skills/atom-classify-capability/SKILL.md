# Classify a Capability

Extract the primary outcome, artifact, authority, evaluation boundary, dependencies, and risk; apply the classification decision order; identify confusable capabilities; and return a proposed stable ID, taxonomy axes, triggers, exclusions, and duplicate candidates. Do not install, execute, or promote the item.
