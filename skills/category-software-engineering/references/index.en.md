# Software engineering: Atomic Skills

Create, change, verify, ship, or operate executable software artifacts.

## Atomic Skills

- `atom-audit-source-security` — **Audit source security**: Return evidence-backed vulnerability findings for a bounded code surface
  - Risk: `read-only`
  - Lifecycle: analyze, verify
- `atom-implement-code-change` — **Implement a code change**: Edit and verify one bounded software behavior
  - Risk: `reversible-write`
  - Lifecycle: create, verify
- `atom-plan-code-change` — **Plan a code change**: Produce an implementation-ready plan without changing source files
  - Risk: `read-only`
  - Lifecycle: plan

Read only the selected Atomic Skill. Use a capability pack when the request has independently useful outcomes.
