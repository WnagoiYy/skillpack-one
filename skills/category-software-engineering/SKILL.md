# Software Engineering Router

1. Identify the requested executable artifact and lifecycle stage.
2. Keep security reviews in `category-security-trust` when a trust property defines success.
3. Read `references/index.en.md` or `references/index.zh-CN.md` for the current atoms.
4. Select the smallest atom set whose outputs cover the request; use a capability pack for independent outcomes.
5. Preserve ambiguity when planning, implementation, and review are not distinguishable from the request.

Do not use this category for general research, visual design without implementation, or Skill governance.
