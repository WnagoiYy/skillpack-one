# Plan a Code Change

Inspect the relevant repository evidence, define the behavioral change and non-goals, identify exact files or components, and produce ordered implementation and verification steps. Call out unknowns and risks. Do not edit source files; requests that include implementation belong to `atom-implement-code-change` or a software-delivery pack.
