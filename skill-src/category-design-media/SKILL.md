# Design and Media Router

1. Identify the medium, audience, design constraints, and required editable artifact.
2. Read the localized Atomic Skill index in `references/`.
3. Distinguish interface design from frontend code implementation and data charts from illustration.
4. Select the least-privileged atom set and retain source asset provenance.

Do not use this category when executable code or quantitative correctness is the primary result.
